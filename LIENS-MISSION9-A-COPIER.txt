CE QU'IL FAUT ESSAYER EN PREMIER (5 minutes)
---------------------------------------------------------------------
1. /admin/ → Contrôle des comptes → « Réinitialisations d'accès » :
   enregistrez vos coordonnées de contact. Elles sont affichées telles quelles par
   « Mot de passe oublié » — aucun numéro n'est inventé par le logiciel.

2. /manager → « Codes d'inscription » → « Générer un code unique d'inscription ».
   Le code s'affiche une seule fois, avec un lien direct.

3. Ouvrez ce lien : la fenêtre « Code d'autorisation d'inscription » s'ouvre,
   le formulaire reste inaccessible. Après vérification, la fenêtre se ferme et le
   formulaire complet apparaît. Le code n'est consommé qu'à l'envoi du dossier.

4. /merchant/ → Gestion de mon équipe → « Demandes de comptes de mon personnel » :
   validez une demande. Les places disponibles sont vérifiées automatiquement.

5. Sous la page de connexion marchand ou gestionnaire : « Mot de passe oublié ? ».

6. Réinitialiser un accès depuis /merchant-control (console marchands) :
   la fenêtre affiche DEUX valeurs qui fonctionnent toutes les deux —
   • le code provisoire « CGF-MHCMF3 » (initiales + 6 caractères) : à saisir dans
     « Mot de passe oublié ? » sur la page de connexion ;
   • le mot de passe à 6 chiffres « 611309 » : à saisir directement à la connexion.
   Les tirets, les espaces et les minuscules n'ont aucune importance.
